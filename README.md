# Tarteel — Quran Learning App

A modern, mobile-first Quran learning platform inspired by the best learning patterns in contemporary Quran apps.

## Stack

- React + Vite + Tailwind CSS
- Node.js + Express
- PostgreSQL + Prisma
- REST API
- JWT authentication foundation

## Monorepo

- `client/` — React frontend
- `server/` — Express API
- `prisma/` — database schema

## Current MVP

- Quran home dashboard
- Surah browsing
- Quran reader
- Audio-ready reader controls
- Bookmarks and progress UI
- Memorization dashboard
- Responsive mobile-first design

## Development

```bash
npm install
npm run dev
```

See the individual `client` and `server` packages for environment configuration.
